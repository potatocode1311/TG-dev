To view & run locally:

Download Android Studio: https://developer.android.com/studio

Clone the repo, or download the zip and extract the project locally from the repo here: https://github.com/potatocode1311/TG-dev

Open Android Studio: File - > Import Project - > select the TG-dev folder you extracted or cloned from the previous step

Connect your physical android device and enable USB debugging, or use an emulator and click run from the quick menu or from the top menu Run - > Run 'app'

Emulator - OPTIONAL: To use an emulator use the top menu and go to Tools - > Device manager, select the + icon -> Create Virtual Device from the new window that appears.  Select the device you wish to run with default settings, then click the start icon in the Device Manager window that appears for the device you selected, it will take a moment to boot up just like a real physical device. Make sure the device is selected under the 'Available Devices' drop down menu, then click Run 'app' or use the top menu to also run the app, the app should appear on the device automatically after building.
